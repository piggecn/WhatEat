Wikimedia Commons

维基共享资源，无需 API Key，直接可用；图片多为 CC 大图。国内直连可能超时，建议配合下方「代理」使用。

默认搜索渠道

新增食谱「找图」时默认使用的渠道；编辑页内也可临时切换。

代理设置

访问外网 API（尤其 Wikimedia）在部分地区不稳定，可填代理。支持 http / https / socks5 / socks5h。

⚠ 若服务运行在 Docker 容器内，代理地址不能用 127.0.0.1（那是容器自身）。请填宿主机局域网 IP（如 http://192.168.1.10:7890）或 host.docker.internal。

食谱 API（导入菜谱）

编辑页新增「导入菜谱」：搜索外部菜谱 / 粘贴文字，一键转成可编辑菜谱。当前为无 Key 免费方案。

其余菜谱（如小红书）用编辑页的「粘贴导入」即可，无需任何 API。
